한 줄 요약

FLUX 3는 이미지·비디오·오디오·액션을 통합하고 최대 20초 영상과 네이티브 오디오를 내세우지만, 원문 조사 시점에는 오픈웨이트가 없어 GB10 로컬 실행 후보가 아니라 API 보조 후보였다.[4]

조사 배경

Black Forest Labs의 Early Access 모델에 대해 통합 멀티모달 기능, API 비용, 오픈웨이트 공개 여부, 로컬 실행 가능성, 기존 LTX-2.5 기반 워크플로우와의 관계를 확인했다. 원문은 2026-08-12 조사 기준으로 작성됐다.[4]

확인한 내용

  • 원문 기준 FLUX 3는 2026-07-23 Early Access로 소개됐고, Self-Flow를 사용해 이미지·비디오·오디오·액션 예측을 하나의 멀티모달 아키텍처로 다룬다고 기록되어 있다.[4]
  • 최대 20초 단일 영상 생성, 네이티브 오디오, T2V·I2V·V2V·키프레임·멀티샷·다국어 대화·립싱크·타이포그래피·Draft 모드가 원문에 정리되어 있다.[4]
  • 원문에 기록된 API 가격은 T2V/I2V 기준 Draft HD $0.06/초, 표준 HD $0.17/초, 표준 FHD $0.29/초이며 V2V는 $0.12~$0.53/초 범위다.[4]
  • 원문에 포함된 벤치마크는 BFL 자체 보고의 preliminary 결과이며, 자체 DevSnack 측정 결과가 아니다.[4]
  • 조사 시점에는 FLUX 3 Dev 오픈웨이트와 HF 웨이트가 공개되지 않아 ComfyUI·GGUF·GB10 로컬 추론은 불가하다고 판단했다. 현 워크플로우에서는 LTX-2.5를 우선하고 FLUX 3는 API 보조로 검토하는 결론이었다.[4]

아직 확인하지 않은 내용

  • FLUX 3를 직접 호출하거나 영상·오디오 품질, 비용, latency를 측정하지 않았다.[4]
  • 한국 및 규제 지역에서의 API 접근 가능 여부를 확인하지 않았다.[4]
  • FLUX 3 Dev 오픈웨이트 공개 시점과 실제 GB10 실행 조건을 확인하지 않았다.[4]
  • 서드파티 무료 크레딧 사이트의 신뢰성이나 실제 FLUX 3 endpoint 제공 여부를 검증하지 않았다.[4]

다음 실험/검증 계획

  1. 공식 Early Access 또는 API 접근 권한과 한국 지역 사용 조건을 확인한다.
  2. 접근이 가능할 때 짧은 T2V·V2V smoke test를 실행하고 비용·생성 시간·오디오·립싱크·타이포그래피 품질을 기록한다.
  3. 기존 LTX-2.5 로컬 결과와 같은 목적의 샘플을 비교하되, FLUX 3는 API 비용을 포함해 판단한다.
  4. 오픈웨이트가 공개되면 그때 GB10 로컬 실행 가능성과 ComfyUI·GGUF 경로를 다시 검증한다.[4]
