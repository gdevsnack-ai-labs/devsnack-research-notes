# Research Note template

> 이 템플릿은 조사 결과를 완성된 Knowledge 글처럼 포장하지 않기 위한 최소 구조다.

```yaml
title: ""
date: "YYYY-MM-DD"
category: models | tools | agents | media | infra | misc
status: research-complete | experiment-candidate | awaiting-test | archived
summary: "한 줄 요약"
original_devsnack_url: "https://devsnack-blog.vercel.app/research/..."
```

## 조사 배경

왜 이 항목을 조사했는지, 원문에서 정의한 범위를 짧게 적는다.

## 확인한 내용

원문과 원문에 수록된 출처에서 확인한 사실·관찰을 적는다. 외부 수치·벤더 주장·커뮤니티 자료는 출처의 성격을 함께 표시한다.

## 아직 확인하지 않은 내용

직접 설치·실행·측정하지 않은 항목, 호환성·재현성·접근 권한처럼 남은 불확실성을 적는다.

## 다음 실험/검증 계획

조사 결과를 사실로 확대하지 않고, 다음에 어떤 환경·조건·측정값을 확인할지 적는다.

## Sources

- 원문에 수록된 출처를 링크한다.
- Note를 재작성할 때 새 조사를 추가하지 않았다면 Original DevSnack URL을 1차 원천으로 명시한다.

## Original DevSnack URL

- `https://devsnack-blog.vercel.app/research/...`
